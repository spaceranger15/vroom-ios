# Public media scope

- Two actual iPhone screenshots show empty offer input and mission setup.
- Screens with recorded earnings, work dates/times, mileage, fuel transactions,
  vehicle details, personal targets and decisions were excluded.
- The API-key settings screen and the Dynamic Island Home Screen capture were excluded.
- The selected screens contain no customer names, addresses, route maps, account
  identifiers, credentials or app backups. Standard iOS status-bar time/battery
  indicators remain visible; they are not work-history records.
- Hidden PNG EXIF/XMP/text metadata was removed. Pixels are unchanged.
- The manifest contains only public relative paths, captions and asset hashes.
- The cover is a decorative vector banner, not a screenshot or working UI.
- This repository starts with a new Git history; earlier private screenshots
  and commits were never copied into it.

The project author and GitHub profile are intentionally identified. This is a
public portfolio, not an anonymous publication. Application source remains private.
No software license to the private implementation is granted by this showcase.
